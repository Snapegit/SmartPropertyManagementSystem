

## 🌟 项目简介

这是一个基于 **Python + Django + uni-app + Vue + MySQL** 构建的完整智慧物业管理系统，功能持续优化中...

### 🧩 功能模块一览

- 用户登录注册
- 房屋信息管理
- 在线报修管理
- 在线缴费管理
- 车位信息管理
- 车位订单管理
- 在线投诉管理
- 我的收藏
- 员工管理
- 用户管理
- 公告信息管理
- 轮播图管理
- 个人中心

## ⚙️ 运行环境与工具要求

为了确保项目顺利运行，请确认您的开发环境满足以下条件：

### ✅ 推荐配置
- **Python**: 3.8  
- **Django**: 2.0  
- **MySQL**: 8.0.41  
- **Node.js**: 16.20.2


⚠️ *温馨提示：版本不一致可能导致依赖冲突或启动失败。*

### 🛠️ 开发工具推荐
- **后端开发**: PyCharm / VS Code  
- **前端开发**: VS Code、HBuilder X  
- **数据库管理**: Navicat / DBeaver / MySQL Workbench  ...
